# Kendine Hakaret Eden Hesap Makinesi

## Bu Nedir Ya?

Bu, dünyanın en kızgın, en iğneleyici ve en gereksiz hesap makinesidir. Her toplama, çıkarma, çarpma ve bölme işleminde size öyle bir hakaret eder ki, matematik ödevinizi yapmaktan vazgeçersiniz. Neden? Çünkü bu hesap makinesi sizin zekanıza inanmıyor. Hem de hiç.

**Özellikler:**
- Gerçekten çalışıyor (inanmayacaksınız).
- Her sonuçtan sonra size kişisel hakaret yağdırır.
- Türkçe hakaretler, çünkü yabancı hakaretler yeterince can yakmaz.
- Sıfıra bölme denerseniz ekstra kızar.

## Nasıl Kullanılır?

```bash
python hakaretli_hesap.py
```

Sonra sayıları girin ve utancınızı yaşayın.
